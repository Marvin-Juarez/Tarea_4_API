# API de Tareas

Esta es una API REST sencilla para administrar tareas. Fue creada con Node.js y Express.

## Funcionalidades

La aplicación permite:

- Crear tareas
- Listar tareas
- Actualizar tareas
- Eliminar tareas

## Requisitos

- Tener Node.js instalado

## Ejecutar la aplicación

Primero instalar las dependencias:
